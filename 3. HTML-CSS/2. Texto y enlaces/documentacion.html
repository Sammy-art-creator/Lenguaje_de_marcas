Introduction

WeatherAPI es una API ficticia diseñada para ofrecer información meteorológica de forma sencilla y rápida a desarrolladores y aplicaciones de terceros. A través de sus endpoints es posible consultar el tiempo actual de distintas ciudades, obtener datos como la temperatura, la humedad o el estado del cielo, y gestionar los usuarios que tienen acceso al servicio.

Esta documentación explica paso a paso cómo autenticarse, qué peticiones se pueden realizar y qué respuestas devuelve cada una, con el fin de que cualquier persona pueda integrar la API en su proyecto sin necesidad de conocimientos previos sobre el servicio. Se recomienda leerla en orden, empezando por la autenticación.

Autenticación

Para utilizar WeatherAPI es necesario identificarse en cada petición mediante una clave de API personal. Esta clave se obtiene al registrarse en el servicio y debe enviarse en la cabecera Authorization de todas las solicitudes. Si la clave falta o no es válida, la API responderá con un error 401 indicando que el acceso no está autorizado.

Es importante mantener la clave en secreto y no compartirla ni publicarla en repositorios públicos. Si sospechas que ha sido comprometida, puedes generar una nueva desde tu panel de usuario, lo que invalidará automáticamente la anterior. Consulta también nuestras buenas prácticas de seguridad para proteger tu cuenta.

Endpoint de usuario

El endpoint de usuarios permite administrar las cuentas que utilizan la API. Mediante él se puede consultar la lista completa de usuarios registrados, así como dar de alta nuevos usuarios enviando sus datos básicos, como el nombre y el correo electrónico, en el cuerpo de la petición en formato JSON.

Devuelve un listado con todos los usuarios registrados. Cada elemento incluye su identificador, nombre y fecha de alta. La respuesta correcta se devuelve con el código 200.

Endpoint de ciudades

El endpoint de ciudades es el núcleo del servicio, ya que da acceso a los datos meteorológicos. Permite conocer qué ciudades están disponibles en la plataforma y consultar el estado del tiempo de cualquiera de ellas utilizando su identificador único, lo que facilita mostrar la información en aplicaciones web o móviles.

Devuelve el listado de ciudades disponibles, cada una con su identificador, nombre y país. Este listado sirve como punto de partida para conocer los identificadores que después se usarán en el resto de consultas.

Devuelve la información meteorológica actual de la ciudad indicada: temperatura en grados Celsius, porcentaje de humedad, velocidad del viento y estado general del cielo. Si el identificador no existe, la API responde con un error 404.
