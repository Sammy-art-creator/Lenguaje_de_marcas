# 📚 Lenguaje de Marcas

Este repositorio reúne los **ejercicios y prácticas** del módulo de Lenguajes de Marcas, organizados por bloques: **XML**, **JSON** y **HTML-CSS**.

## 📁 Estructura del Proyecto

```
Lenguaje_de_marcas/
├── 1. XML/
├── 2. JSON/
├── 3. HTML-CSS/
└── README.md
```

## 🛠️ Tecnologías Usadas

- **XML** 📄 (con XSD para validación y XPath para consultas)
- **JSON** 🗃️
- **HTML5** 🏗️
- **CSS3** 🎨
- **Visual Studio Code** 💻 (como editor)

## 🚀 Cómo Usarlo

1. Clona o descarga el repositorio.
2. Ábrelo en VS Code (`Archivo > Abrir carpeta`).
3. Navega al bloque que quieras revisar.
4. Abre los archivos `.html` en el navegador para ver el resultado.
